# OurTravel 家庭旅遊財務與回憶帳本 ✈️

專為夫妻與家庭未來 5～10 年每次出國打造的旅遊財務紀錄與回憶 App。

---

## 🌟 核心特色與架構

1. **旅程與城市解耦**：單一旅程（例如 🇯🇵 東京＋關西 2027）下可掛載多個城市（東京、京都、大阪），每筆消費可選所屬城市，精確統計各地開銷。
2. **日期＋時間軸 (Timeline)**：保留消費的精準時分（如 18:30 一蘭拉麵），自動產生日程時間軸，不再只是冰冷冷的名細。
3. **現金換匯獨立錢包 (Wallets & FX)**：
   - 換匯（台幣 NT$50,000 → 日圓 ¥235,000）屬於資產兌換，不列入支出。
   - 錢包餘額清晰掌控：日圓現金剩餘多少、出發前總換匯多少。
4. **旅行模式 (Travel Mode)**：
   - 出國途中專用大字體、極簡沉浸介面。
   - 醒目顯示「今日累積支出」、「剩餘預算」、「外幣現金餘額」與超大「＋記一筆」。
5. **📷 照片離線安全儲存 (IndexedDB)**：
   - 支援收據發票或旅遊紀念照片拍照與上傳。
   - 內建離線圖片自動壓縮與微縮圖生成，不受限於一般 localStorage 的 5MB 限制。
6. **信用卡實際請款金額回填**：
   - 國外消費先記外幣，回國收到信用卡帳單後可補填實際台幣請款金額，精準分析海外回饋與真實匯率。
7. **預付支出 vs 旅途即時消費**：
   - 出國前機票、飯店、JR Pass 標記為預付；吃喝玩樂標記為旅程中，報表分明。
8. **🏁 旅程結算完整報告**：
   - 一鍵產生旅遊結算紀念報告（天數、每日平均、支付比例、城市花費、現金剩餘核對）。
9. **離線優先 (PWA)**：
   - 支援 Service Worker 離線快取，飛機上或地下鐵無收訊也能順暢記帳。

## 📁 檔案結構

```text
C:\Users\User\family-travel\
├── index.html          # PWA 主頁面 (支援旅行模式與一般模式切換)
├── style.css           # 精品級深色/旅人視覺設計系統
├── manifest.json       # PWA 主畫面設定
├── sw.js               # Service Worker 離線快取
├── server.js           # 輕量本機預覽伺服器 (Node.js 內建 http)
└── js/
    ├── models.js       # 核心模型、貨幣、分類、支付方式與標籤
    ├── db.js           # IndexedDB 照片壓縮儲存庫
    ├── storage.js      # 本地儲存與快速記帳快取
    ├── calculations.js # 預算進度、換匯錢包餘額與結算報告產生器
    └── app.js          # 主互動邏輯、旅行模式切換與 DOM 渲染
```

## 🚀 啟動方式

在終端機進入專案資料夾後執行：

```powershell
cd C:\Users\User\family-travel
node server.js
```

瀏覽器打開：`http://localhost:3030` 即可使用。
在 Antigravity IDE 裡隨時可以透過 `File -> Open Folder` 開啟 `C:\Users\User\family-travel`。
